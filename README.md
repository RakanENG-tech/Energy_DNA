# Energy DNA Website

A responsive bilingual (English/Arabic) static website for Energy DNA.

## Files
- `index.html` — site content and structure
- `styles.css` — responsive design
- `script.js` — language switcher and mobile navigation

## Publish using GitHub Pages
1. Upload all three website files (`index.html`, `styles.css`, `script.js`) to the root of your `Energy_DNA` repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then press **Save**.
5. Wait for GitHub Pages to publish the site.

## Before launch
- Replace `hello@energy-dna.example` with the team's official public email.
- Add approved photographs to the team section (the current design uses initials placeholders).
- Confirm names, titles, project statuses, and official social links.
- Project descriptions intentionally distinguish concepts/research from validated results.
